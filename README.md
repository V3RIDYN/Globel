# Globel embed prototype

A compact five-letter word game styled for The Globe's SNO website.

## Open locally
Double-click `index.html`.

## Included
- Responsive newspaper-style layout
- Lato for title, tiles, and keys
- Times New Roman for secondary text
- Compact dimensions for a SNO content page
- Keyboard and touchscreen controls
- Help panel
- `embed-code.html` with the future SNO iframe code

## Prototype limitation
The answer is random and guesses are not yet checked against a complete dictionary. The next production step is daily puzzles, saved progress, validation, statistics, and sharing.
